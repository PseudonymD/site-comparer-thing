# Scoring specification

This document is the single source of truth for the analog score. It is implemented twice:

* **Python:** `pipeline/scoring.py`, used for validation (`pipeline/report.md`)
* **TypeScript:** `web/src/scoring.ts`, used in the browser Web Worker

`docs/fixtures/scoring_fixture.json` is generated by the Python implementation
(`python -m pipeline.tests.make_fixture`). Two tests check against it:

* `pipeline/tests/test_scoring.py` checks that the fixture is current.
* `web/tests/scoring.test.ts` checks that the TS implementation reproduces it. The float64 path must match to 1e-12 and the float32 worker path to 1e-5.

## Inputs

| Symbol | Meaning |
|---|---|
| `q_if ∈ {0..255}` | stored value of feature *f* for land cell *i* (`features.bin`, cell-major `[cell][18]`) |
| `z_if = q_if / 255` | Earth-land percentile of the cell's raw value, `CDF_f(x_if)` (mid-rank for ties) |
| `t_f ∈ [0,1]` | target percentile `CDF_f(clamp(T_f, min_f, max_f))` (`targets.json → vector`) |
| `w_f ≥ 0` | user weight (UI sliders 0–3; defaults in `targets.json → weights`) |

## Score

```
S_i  = 1 − sqrt( Σ_f w_f (z_if − t_f)² / Σ_f w_f )
c_if = w_f (z_if − t_f)² / Σ_f w_f            (per-feature contribution; Σ_f c_if = (1 − S_i)²)
```

`S_i ∈ [0, 1]`: 1 means the cell matches the target percentile on every weighted feature, 0 means maximally different.
If every weight is 0, the score is undefined: Python returns 0 and the TS implementation returns 1 for all cells.

## Hard filters

A filter `(f, τ)` in real units excludes cells whose raw value is above τ. It is converted to a percentile threshold with
the 101 breakpoints `b_0..b_100` stored in `meta.json`:

```
k  = max{ j : b_j ≤ τ }               (k = −1 → z* = 0 ;  k = 100 → z* = 1, nothing excluded)
z* = (k + (τ − b_k) / (b_{k+1} − b_k)) / 100
S_i = 0   if  z_if > z*
```

## Novelty

```
d_i = great-circle distance (km, R = 6371.0088) from the cell centre to the nearest known analog
N_i = min(d_i / D0, 1),   D0 = 2000 km   (config.NOVELTY_SATURATION_KM, meta.novelty_saturation_km)
B_i = (1 − α) S_i + α N_i      (B_i = 0 when S_i = 0, i.e. filtered cells stay filtered)
```

α is the "novelty weight" slider (0–0.6). The map colours, the top-N list and the ranking use `B_i`. The site card shows `S_i`.

## Real units

`value(z) = linear interpolation of breakpoints b_0..b_100 at position z·100`, which is the inverse CDF. The UI uses it to show
real-unit values for cells and targets.

## Sites (top-N)

The worker takes roughly the best 6000 cells by `B_i` and merges 8-neighbour adjacent cells (longitude wraps) with
union-find. Each site is represented by its best cell, and sites are ranked by that cell's `B_i`.
